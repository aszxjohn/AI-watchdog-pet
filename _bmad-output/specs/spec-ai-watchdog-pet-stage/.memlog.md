- (capability) CAP-1 偵測 session：唯讀偵測 Claude Code、Codex CLI、Gemini CLI、Cursor、Copilot CLI 的 session，歸成 8 狀態 | 各工具開一個 session 會出現在畫面，狀態變化在延遲目標內反映；前後比對各工具設定檔雜湊不變
- (capability) CAP-2 一個 session 一隻：每個追蹤中的 session 從池子分到一隻角色，池子用完前不重複，session 結束放回 | K≤池子大小個 session 時畫面上 K 隻各不相同；結束一個 session 其角色離場並可再被分配
- (capability) CAP-3 管理 session：使用者指定哪些 session 顯示、哪些釋放不追蹤，之後可改回 | 釋放的 session 角色收回、仍留在管理清單；改回顯示後重新分配角色
- (capability) CAP-4 透明置頂畫布：角色在使用者選的一個螢幕上、透明置頂且滑鼠穿透的畫布裡遊走 | 點空白處操作到底下的視窗；游標在角色身上才被畫布接收
- (capability) CAP-5 捏起來拖走：左鍵拖曳角色到別處，包有實作就演被捏起來的動作，放開後從放下處直接恢復遊走 | 拖曳中角色跟著游標、不掉落；沒實作 grab 的包角色照原樣被拎著走
- (capability) CAP-6 右鍵選單與入口：右鍵角色開選單（這個角色的編輯頁、管理 session、暫停／顯示）；入口在 macOS 選單列與 Windows 系統匣，不佔 Dock／工作列 | 三個選單項各自打開對應功能；Dock／工作列沒有圖示
- (capability) CAP-7 名牌與標記：舞台在每隻角色上方畫 session 顯示名稱與狀態標記，推測出來的狀態用另一種標記樣式，可逐角色關閉 | 同一狀態的確定與推測兩種標記看得出差別；關閉後兩者都不畫
- (capability) CAP-8 編輯角色參數：編輯頁上半部固定參數（大小、加入池子、遊走偏好、名牌與標記顯示），下半部依角色包宣告自動產生（bool／int／number／choice／asset）；舞台有設定用舞台的，沒有用包預設；調整只存舞台、以角色為單位 | 新角色包不寫任何 UI 程式就出現可調欄位；重新匯入同一包後調整仍在
- (capability) CAP-9 池子組成：使用者勾選哪幾包上場，每個角色一個『加入池子』開關（舞台設定，編輯頁與包管理頁同一個值） | 關掉某角色的開關後它不再被分配；兩個頁面顯示一致
- (capability) CAP-10 匯入匯出角色包：匯入 .awpet 時驗證並拒絕危險或不相容的包（附原因），同 id 須確認才替換，失敗回復舊版；匯出只含角色包本身 | 含 .. 路徑、超大圖片、API 版本不相容的測試包都被拒並說明原因；匯出檔不含使用者調整
- (capability) CAP-11 依狀態演出：每隻角色依 8 狀態演出；包沒做的狀態演包的後備演出，再沒有演舞台佔位；『做完了』是過場，幾秒後轉『等你回覆』 | 只實作部分狀態的測試包在其餘狀態演後備或佔位；一輪結束先 done 再 waiting
- (capability) CAP-12 跨包通用互動：被擊中、靠近／碰撞、進場／離場、狀態廣播、被捏起來五種；舞台提供通用飛行物件，包可用自訂物件，沒指定或不認得就丟隨機通用物件；命中由舞台判定 | A 包射中 B 包角色時 B 收到 hit；沒處理 hit 的包無反應也不報錯；不認得的物件仍會丟出通用物件
- (capability) CAP-13 同包特殊互動：同一包的角色可以有包內自訂的互動 | 一個多角色測試包能讓兩隻己方角色對彼此的事件做專屬反應
- (capability) CAP-14 角色移動請求：包可請自己的角色停下／恢復遊走、轉向，不能指定位置；使用者設成不遊走就一定不動 | 包呼叫停下後角色停在原地；使用者設不遊走時包的恢復請求無效
- (capability) CAP-15 角色包安全隔離：包程式碰不到檔案、網路、系統指令、對話內容、別的包與舞台設定；出錯只影響自己，當掉自動重啟最多 3 次，仍失敗視同停用並顯示原因；停用、移除或角色消失時畫面上的角色換成池子裡其他角色 | 惡意測試包的連網、讀檔嘗試全部失敗；讓一包當掉時其他角色照常演出，第 4 次失敗後該包標為失敗且其角色被替換
- (capability) CAP-16 展示與示範：示範模式用假 session 輪播 8 狀態並照池子分配；展示模式可指定任何角色與狀態，不存檔、不佔池子；編輯頁預覽用展示模式 | 沒有真 session 也能看到每個狀態的演出；展示指定的角色不影響真 session 的分配
- (capability) CAP-17 運行紀錄與設定保護：每小時一個紀錄檔只留 24 小時；設定檔壞掉時留 .broken 備份、改用預設，不被默默蓋掉 | 塞入壞掉的設定檔後 app 正常啟動且原檔被保留
- (capability) CAP-18 沒有角色包也能跑：沒安裝任何角色包時，偵測、面板、管理 session 都照常 | 全新安裝啟動後畫布為空，面板能列出偵測到的 session
