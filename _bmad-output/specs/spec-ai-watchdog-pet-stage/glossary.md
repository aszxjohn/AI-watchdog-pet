# 術語

| 術語 | 意思 |
| --- | --- |
| 舞台 | 主程式。負責偵測 session、管理世界與畫布、載入角色包、提供面板；沒有角色包也能完整運作。 |
| 角色包 | `.awpet` 檔，內含一個或多個角色的程式與素材，在沙盒裡執行，只能透過舞台 API 溝通。 |
| 角色 | 角色包裡的一個角色定義，以 `<packId>/<characterId>` 識別；參數調整以它為單位。 |
| actor | 畫面上的一隻角色。一個 session 分到一個角色時就產生一個 actor（`actorId`）；同一個角色可以同時有好幾個 actor。 |
| session | 某個 AI 工具的一次對話，以 `<source>:<原生 id>` 識別。 |
| 池子 | 可以被分配給 session 的角色集合＝上場的包裡，「加入池子」開關為開的角色。 |
| 固定參數 | 舞台定義、每個角色都有的參數：大小、加入池子、遊走偏好、名牌與標記顯示。 |
| 包參數 | 角色包在 manifest 宣告、開放給使用者調整的參數；編輯頁依宣告自動產生欄位。 |
| 覆蓋值 | 使用者在舞台設定的參數值；只存在舞台，有覆蓋值就用它，沒有就用包的預設值。 |
| 通用互動 | 舞台定義、跨包都適用的五種事件：`hit`、`proximity`、`enter`／`leave`、`state-broadcast`、`grab`。 |
| 推測狀態 | 紀錄檔抓不到、由舞台依時間推測出來的狀態（例如工具執行太久，推測成要你批准），標記樣式和確定的狀態不同。 |
| 佔位演出 | 包沒做某個狀態、也沒宣告後備演出時，舞台自己畫的替代演出。 |
| 展示模式／示範模式 | 不用真 session 也能看演出：示範模式輪播 8 種狀態並照池子分配；展示模式可以指定任何角色和狀態。 |

## 8 種狀態

| 代碼 | 顯示名 | 意思 |
| --- | --- | --- |
| `waiting` | 等你回覆 | AI 這一輪講完了，等使用者回覆 |
| `thinking` | 思考中 | 使用者送出訊息後，AI 還沒開始呼叫工具 |
| `working` | 工作中 | AI 正在執行工具 |
| `approval` | 要你批准 | AI 卡在權限詢問，等使用者批准 |
| `decision` | 要你決定 | AI 問了問題或給了選項，等使用者選 |
| `done` | 做完了 | 一輪剛結束時的過場，幾秒後轉成 `waiting` |
| `idle` | 休息中 | 一段時間沒有任何動靜 |
| `error` | 出錯了 | API 錯誤或執行失敗 |
